Общие таймеры + ссылка в интернете — настройка
==============================================

Что даёт эта штука:
- Все, кто открыл ссылку, видят ОДНИ и те же таймеры: кто-то убил босса — у всех
  отметка и отсчёт появились сами (проверка раз в 15 секунд, кнопка «☁» — синхронизировать сейчас).
- Настройки (звук, фильтры, зум карты) у каждого свои — общими стали только отметки.
- Без интернета всё продолжает работать: отметки лежат в браузере и уезжают на сервер,
  когда связь вернётся. Кнопка покажет «☁ нет связи».

Что нужно сделать (3 шага, всё в браузере, без установки программ).

Шаг 1. Бесплатный проект в Supabase
-----------------------------------
1. Открой https://supabase.com и зарегистрируйся (можно через GitHub).
2. New project: имя любое (например raidbosses), пароль БД любой, регион ближе к тебе.
3. Дождись, пока проект создастся (1-2 минуты).

Шаг 2. Таблица
--------------
1. В проекте слева открой: SQL Editor → New query.
2. Вставь целиком то, что ниже, и нажми Run.

-- ---------- начало SQL ----------
create table if not exists public.rb_kills (
  id         text primary key,
  killed_at  bigint  not null default 0,
  r0         bigint  not null default 0,
  r1         bigint  not null default 0,
  checks     jsonb   not null default '[]'::jsonb,
  deleted    boolean not null default false,
  updated_at bigint  not null default 0
);

alter table public.rb_kills enable row level security;

create policy "rb read"   on public.rb_kills for select using (true);
create policy "rb insert" on public.rb_kills for insert with check (true);
create policy "rb update" on public.rb_kills for update using (true) with check (true);
-- ---------- конец SQL ----------

Шаг 3. Ключи в index.html
-------------------------
1. В Supabase: Project Settings (шестерёнка) → API.
2. Скопируй два значения:
   - Project URL       — вида https://abcdefghijkl.supabase.co
   - anon public key   — длинная строка (НЕ service_role!).
3. Открой index.html любым редактором (Блокнот подойдёт) и найди строки:

const SYNC = {
  url: '',
  key: '',
  table: 'rb_kills',
  pollMs: 15000
};

   Впиши свои значения между кавычек:

const SYNC = {
  url: 'https://abcdefghijkl.supabase.co',
  key: 'eyJhbGciOi...твоя-длинная-строка...',
  table: 'rb_kills',
  pollMs: 15000
};

4. Сохрани файл и открой в браузере. Кнопка «☁» должна показать «☁ общие · ЧЧ:ММ».
   Если показывает «☁ нет связи» — либо ключи неверные, либо нет интернета.

Как выложить в интернет (чтобы была ссылка)
-------------------------------------------
Статика, сервер не нужен. GitHub Pages, без установки git — через сайт:

1. Зарегистрируйся на https://github.com (если ещё нет аккаунта).
2. New repository → имя, например raidbosses → Public → Create repository.
3. На странице репозитория: «uploading an existing file» → перетащи два файла:
   index.html и map-lu4.webp (map обязательна, иначе карта будет пустой) → Commit changes.
4. Settings (в репозитории) → Pages → Source: «Deploy from a branch» →
   Branch: main, папка / (root) → Save.
5. Через 1-2 минуты ссылка: https://ТВОЙ-НИК.github.io/raidbosses/
   Эту ссылку кидай в Discord/Telegram — открывается с телефона и с ПК.

Обновить файл потом: в репозитории открыть index.html → карандаш/Upload file → закоммитить.
Ссылка не меняется.

Если Pages не подходит, равноценная замена: Cloudflare Pages или Netlify Drop
(перетащить папку с двумя файлами, ссылка будет своя).

Как это работает внутри (чтобы не было сюрпризов)
-------------------------------------------------
- Одна строка на босса. При каждой правке ставится метка времени updated_at;
  при обмене побеждает та строка, у которой метка больше («кто позже поменял»).
- Удаление («↺ Сброс») ставит deleted=true, а не стирает строку. Иначе другой игрок
  со старой копией «воскресил» бы таймер.
- Метка всегда выше всего, что клиент уже видел, поэтому даже при расхождении часов
  (у кого-то время на 5 минут вперёд) удаление и правки не проигрывают старым данным.
- Своя правка, которая ещё не уехала на сервер, не перетирается пришедшей чужой.

Риски и ограничения — честно
---------------------------
- anon-ключ виден всем, кто откроет страницу (так устроен Supabase). Правила в таблице
  открытые: кто угодно с ключом и ссылкой может менять и стирать отметки.
  Для компании друзей это нормально. Если нужно жёстче — не давай ссылку в открытые каналы;
  можно добавить «код отряда» (общий пароль) — скажи, допилю.
- Бесплатный проект Supabase засыпает после ~недели без запросов. Первый запрос после сна
  идёт медленнее; индикатор может мигнуть «нет связи» и через пару секунд стать «общие».
- Параллельные правки одного и того же босса в одну секунду: останется одна (последняя).
  Остальные подхватят её при следующем обмене.
- Если удалил/пересоздал проект Supabase — старые ключи перестают работать, надо вписать новые.

Что проверено
-------------
Синхронизация прогнана на локальной заглушке REST API в нескольких профилях браузера:
создание отметки, подхват вторым игроком, сброс с распространением удаления,
гонка «правка в момент чужого удаления», защита при сдвинутых часах, работа с file://
и поведение при недоступном сервере. Боевой Supabase не проверялся (нет аккаунта) —
первый реальный запуск делай за себя и смотри на кнопку «☁».
