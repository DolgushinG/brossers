# Рейд-боссы Lu4 — карта и таймер респа

Сайт: **https://dolgushing.github.io/brossers/**

Офлайн-страница: карта мира с точками боссов, таймеры до респа, ручной ввод времени смерти,
общие таймеры для группы.

## Как открыть

- По ссылке выше — с телефона или ПК, ничего скачивать не надо.
- Либо скачай `index.html` и `map-lu4.webp` в одну папку и открой `index.html` двойным кликом.
  Интернет не нужен.

## Что на экране

- Слева карта мира, справа список.
- У убитых боссов на карте подпись «имя · уровень · таймер до респа».
- Точки: зелёная — жив, синяя — таймер идёт, жёлтая — возможен респ, красная — респ.
- Колесо мыши — масштаб, зажать и тянуть — перемещение, «⟳ Весь мир» — обзор.

## Как пользоваться

1. Убил босса → клик по точке → «🔪 Убил».
2. Время смерти можно вписать руками: «🕓 Убил в…» (если убил раньше, а отметку ставишь сейчас).
   Есть быстрые кнопки «сейчас / −5 / −15 / −30 мин / −1 ч / −3 ч» и любая дата вручную.
3. Пришёл проверить спавн → «✓ Проверил» (история проверок сохраняется).
4. Босс зареспился → «↺ Сброс», затем снова «🔪 Убил».
5. «мой ур. ± N» — оставить только боссов под уровень персонажа.
6. Боссы с «фикс. респ» (Core, Orfen, Queen Ant) — «🕓 Задать респ».

## Что запоминается само

Отметки, проверки, таймеры, звук, «предупредить за N мин», поиск, фильтры, сортировка,
положение и масштаб карты, открытая карточка босса, твоё имя и видимость лога.
Всё в `localStorage` браузера.

## Общие таймеры

Включены — отметки общие для всех, кто открыл ссылку. Кнопка «☁» в тулбаре:

- `☁ общие · ЧЧ:ММ` — связь с сервером есть, время последнего обмена;
- `☁ нет связи` — сервер не ответил, правки лежат локально и уйдут, когда связь вернётся;
- клик по кнопке — синхронизировать сейчас (обычно хватает автоматических каждые 15 сек).

Бэкенд — бесплатный Supabase. Подробности и переустановка: [sync-setup.txt](sync-setup.txt).

## Лог событий

Слева панель «Лог»: кто, когда и что сделал — убил босса, вписал время, проверил спавн, сбросил таймер.

- Своё имя: кнопка «✎» в шапке лога (или запрос при первом действии). Без имени — «гость».
- Имя хранится в твоём браузере, в `localStorage`; в лог попадает только текст имени.
- Без связи записи видны сразу, но бледно (ещё не отправлены), и уезжают при следующем обмене.
- Скрыть/показать панель — кнопка «📜 Лог» в тулбаре.

Для лога нужна таблица `rb_log` в Supabase — SQL в [sync-setup.txt](sync-setup.txt), блок «ТОЛЬКО ЛОГ».
Пока таблицы нет, панель честно пишет «Лог не настроен», а таймеры работают как обычно.

## Передача отметок файлом

- «💾 Сохранить» — скачивает `raidbosses-save.json` с отметками и таймерами.
- «📂 Загрузить» — выбираешь файл и видишь те же отметки.

## Ограничения

- Ссылку получают все, кому ты её дал, и любой из них может менять общие отметки —
  регистрации нет. Не кидай в открытые каналы.
- В исходниках страницы виден публичный ключ Supabase (`sb_publishable_…`). Это нормально,
  но ключ `secret`/`service_role` туда класть нельзя никогда.
- Бесплатный проект Supabase засыпает после ~недели без запросов: первый запрос после сна
  медленный, индикатор может мигнуть «нет связи» и вернуться в «общие».
